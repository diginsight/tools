This chapter covers the repository's minor components: the Tooling and Peripheral artifacts that are documented in compact pages because they are not primary business-capable components.

## 🔑 Key points

- Tooling and peripheral components are documented compactly rather than as full system components.
- The scaffold APIs remain intentionally documented as placeholders whose purpose is not established by source evidence.
- The MIP inspector projects are the only non-template tooling components with a clear technical role.
